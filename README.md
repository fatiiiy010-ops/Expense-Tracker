# 💰 Expense Tracker

A simple beginner-friendly Expense Tracker built with Python.

## 📌 About

This Expense Tracker allows users to add and manage their daily expenses.
The program stores the expense name and amount and can display all expenses
and calculate the total expense.

## ✨ Features

- ➕ Add an expense
- 📋 Display all expenses
- 💰 Calculate total expenses
- ⚠️ Show a message when no expenses are available
- 🔢 Input expense amount
- 📋 Simple menu system
- 🚪 Exit option

## 🛠️ Concepts Used

- Variables
- Lists
- Functions
- `while` loop
- `for` loop
- `if / else`
- User input
- `append()`
- `return`
- List unpacking
- F-strings

## ▶️ How to Run
